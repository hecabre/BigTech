- **Conexión:** Es tu primer problema de comparar strings carácter por carácter.

## Guía — abre una pista solo cuando te atores

> [!question]- Pista 1 — ¿qué observar?
> El prefijo común nunca puede ser más largo que el string más corto.

> [!question]- Pista 2 — ¿qué estructura usar?
> Toma el primer string como candidato y compáralo contra cada uno de los demás.

> [!question]- Pista 3 — el algoritmo
> Mientras el string actual no empiece con el candidato, recórtale el último carácter.

> [!warning]- Trampa común
> No manejar el arreglo con un solo string o el string vacío `""`.

> [!success]- Complejidad meta
> Tiempo O(S), donde S es el total de caracteres; espacio O(1)
