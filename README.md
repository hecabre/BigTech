## Uso semanal

1. Abre el [índice semanal](Semanas/00-%C3%8Dndice-semanal.md) y entra al día actual.
2. Completa primero las tareas esenciales ya escritas en esa nota.
3. Durante el transporte, abre la lectura enlazada para ese día.
4. Si queda tiempo y energía, abre el problema adicional de LeetCode.
5. El viernes, completa el cierre y actualiza el tablero.

> El calendario es una guía, no una deuda. Si una semana se complica, se mueve únicamente lo esencial al siguiente lunes.
