# Calendario semanal: Big Tech SDE New Grad + AWS

> [!info] Punto de partida
> Inicio: lunes 7 de septiembre de 2026.  
> AWS: comenzando el módulo 6 de Cloud Practitioner.  
> Meta: llegar a mayo de 2027 preparado para procesos SDE New Grad, con Cloud Practitioner, Solutions Architect – Associate y una migración demostrable a AWS.

Nota relacionada: [[00-Plan-principal]]

## Reglas del calendario

- Solamente se estudia de lunes a viernes.
- Durante el semestre, el lunes concentra el trabajo profundo; de martes a viernes las sesiones duran 30–45 minutos.
- Desde enero, las sesiones cortas pueden crecer a 60–90 minutos si ya disminuyó la carga escolar.
- El trabajo tiene prioridad durante el horario laboral, incluso en home office.
- Si dormiste menos de seis horas, cambia el problema nuevo por repaso, flashcards o lectura.
- Una tarea pendiente se mueve al siguiente lunes; no invade sábado ni domingo.
- En LeetCode, el primer intento se hace sin IA durante 25–35 minutos.
- No se presenta una certificación por calendario: se presenta al cumplir el criterio de preparación.
- Si aparece una vacante New Grad 2027 compatible, se aplica aunque todavía no hayas terminado todas las certificaciones.

## Ritmo base

### Septiembre–diciembre

- **Lunes:** 2 h AWS + 60–90 min algoritmos + 60–90 min laboratorio/proyecto.
- **Martes:** 30–45 min de problema o reintento.
- **Miércoles:** 30–45 min de AWS, preguntas o notas.
- **Jueves:** 30–45 min de problema o fundamentos.
- **Viernes:** 30–45 min de repaso, STAR, inglés o búsqueda laboral.

### Enero–mayo

- **Lunes:** 2–3 h de tema principal + 70 min de coding + 60–90 min de proyecto.
- **Martes:** 45–60 min de coding.
- **Miércoles:** 45–60 min de AWS, proyecto o fundamentos.
- **Jueves:** 45–60 min de coding.
- **Viernes:** simulacro, entrevista conductual y postulaciones.
