# Pruebas, debugging y observabilidad

Una prueba unitaria valida una pieza aislada; integración valida contratos entre componentes; end-to-end valida un flujo. La pirámide favorece muchas pruebas rápidas y pocas pruebas costosas.

Para depurar, reproduce, reduce, formula una hipótesis, mide y cambia una variable. Evita “arreglos” sin evidencia. Registra el síntoma, causa raíz, corrección y mecanismo preventivo.

Logs explican eventos; métricas muestran tendencias; trazas conectan una petición entre servicios. Una alerta debe corresponder a impacto o acción posible.
