# Amazon OA y entrevista de código

La preparación oficial de Amazon para roles universitarios describe el OA como una etapa inicial y recomienda familiarizarse con el entorno. En coding se evalúa aplicar fundamentos, no memorizar soluciones.

En cada problema: aclara requisitos, propone fuerza bruta, mejora usando restricciones, explica antes de programar, prueba manualmente y calcula complejidad. Bajo tiempo, busca primero una solución correcta y verificable.

Practica sin autocompletado y verbaliza decisiones. Reserva minutos finales para casos límite, nombres, índices y retorno.

## Recuperación

1. ¿Qué harás en los primeros cinco minutos?
2. ¿Cuándo abandonarías una optimización incompleta?
3. ¿Qué revisarás antes de enviar?

Fuente: [preparación oficial para SDE universitario](https://www.amazon.jobs/content/de/how-we-hire/university-roles/sde).
