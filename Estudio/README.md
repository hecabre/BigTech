# Lecturas para el transporte público

Ruta de lectura de 10–20 minutos por día. Cada nota diaria enlaza la lectura correspondiente; no es necesario copiar nada.

## Método

1. Leer una sola sección durante el trayecto.
2. Cerrar la nota y explicar la idea con tus palabras.
3. Responder la pregunta de recuperación sin mirar.
4. Escribir únicamente una frase en “Qué entendí” dentro de la nota del día.
